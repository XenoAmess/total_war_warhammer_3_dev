## 故障修正与边界

首次通用杀死人物接口无法移除未招募候选，旧报告保留该失败。新 `native_pool.lua` 根据唯一签名和自然淘汰调用链，核对人物、派系、职业池、条目与容器，再调用引擎清理、压实与尾部清理；Lua 不直接写人物或容器字段。

一次早期 UI 实验在旧卡片打开时读取已删除人物姓名，触发引擎 NULL 访问。已改为 `ClosePanel` 加 `CloseCurrentHUDPanel()`、等待面板不可见后才提交，后台也拒绝面板打开时移除；连续真实按钮验证通过。原始崩溃证据保留，没有改成通过。

缺少前置、签名不唯一、调用链或结构变化时，在生成前拒绝。类型需有普通自动生成标记和实际职业；冰雪宫廷、传奇和未知类型继续拒绝。其他种族、组合 Mod、特殊首都、联机和混沌魔域没有完整实机验收，不承诺兼容。
