# 《全面战争：战锤 3》顾问语音替换与 DLC 资源预研

日期：2026-10-31。状态：原版资源静态检查完成，音频逐条定位与换声原型待验证。

后续研究已完成音频提取、中文文案清单和单文件替换包的静态验证，见[提取与换声机制报告](advisor-audio-extraction-and-replacement.md)。以下保留第一阶段观察及其当时的验证边界。

本报告用于判断顾问换声 Mod 的覆盖范围，回答顾问是否随角色变化、是否需要按派系分别替换，以及缺少 DLC 是否影响发现本地音频和文案。机器身份、文件指纹、解析计数与样本关联见[本次证据清单](advisor-voice-research-evidence-2026-10-31.json)。

## 1. 结论

| 问题 | 结论 | 证据边界 |
| --- | --- | --- |
| 游戏是否有会主动说话的顾问 | 有。官方称为 Advisor，可提供语音与文字提示 | 官方手册确认功能；本机存在战役与战斗提示声音库 |
| 每个角色的顾问是否相同 | 大量提示共用通用顾问身份；序章、旁白及剧情人物另有身份 | 2,969 条提示中，1,928 条指定 `standard_advisor`；身份和头像绑定不能直接当作独立配音演员数量 |
| 换声是否需要每个派系各改一份 | 共用音频可以一次替换并影响所有引用它的提示；专属提示需要另行覆盖 | 实现单位应是提示事件及其实际媒体文件，不能只按派系名称或顾问头像划分 |
| 缺 DLC 是否限制发现本地音频与文案 | DLC 许可本身不妨碍读取已经安装的普通 `.pack` 条目；通常无需买齐 DLC 才开展资源发现 | 本次未检查账号 DLC 拥有列表，也未完成所有事件到音频文件的关联，不能宣称已验证未购 DLC 的全部资源齐备 |

可以进入顾问音频清单和单句替换原型阶段。当前证据支持资源可查和存在共用结构；全覆盖换声仍需逐条媒体定位与实际播放验收。

## 3. 顾问身份和声音库结构

### 3.1 顾问提示与角色语音

官方手册第 5 页的 “The Advisor & Help System” 说明，顾问会根据游玩过程提供引导，提示可调整为语音、文字或两者同时显示。参见[官方手册](https://shared.akamai.steamstatic.com/store_item_assets/steam/apps/1142710/manuals/TWW3_PC_STEAM_MANUAL_EN.pdf?t=1779441058)。

换声范围需要区分常规教学与玩法提示、序章和剧情对话，以及领主或单位被选中、接令时的角色语音。它们都可能被玩家描述为“有人说话”，但资源关联和替换范围不同。战斗中的具体播报应按实际声音事件归类，不能仅凭听感一律归入通用顾问。

### 3.2 本机顾问数据

`db.pack` 的 `db/advisors_tables/data__` 为版本 2，共 13 行，包含通用顾问、旁白、序章人物和若干剧情角色的身份与头像绑定。

`db/advice_levels_tables/data__` 为版本 5，共 2,969 行，其 `advisor_name` 分布如下：

| `advisor_name` | 提示记录数 |
| --- | ---: |
| `standard_advisor` | 1,928 |
| `faction_leader` | 613 |
| `prologue_advisor` | 215 |
| `narrator` | 140 |
| `prologue_yuri_0` | 23 |
| `prologue_yuri_1` | 25 |
| `prologue_yuri_2` | 7 |
| `prologue_yuri_3` | 4 |
| `skreech` | 5 |
| `archaon` | 4 |
| `nagash` | 4 |
| `isabella` | 1 |
| 合计 | 2,969 |

提示表使用了 12 种身份；顾问定义表中的第 13 种 `prologue_yuri_4` 没有出现在这份提示表的引用中。这些数量统计的是展示身份与提示记录，不能解释成 12 或 13 位配音演员，也不能把 `faction_leader` 的 613 条提示都归给一个说话者。

这张表支持“大量提示共享通用顾问身份”的判断，也表明全提示换声的范围大于只替换通用顾问。

### 3.3 提示声音库与实际媒体

本机 `audio_en_bnk.pack` 中，目录 `audio/wwise/english(uk)/` 包含以下六个提示声音库：

```text
battle_advice__core.bnk
campaign_advice__core.bnk
campaign_advice_1385955645__core.bnk
campaign_advice_1927722379__core.bnk
campaign_advice_2173257825__core.bnk
campaign_advice_909104986__core.bnk
```

`audio_cn_bnk.pack` 的 `audio/wwise/chinese/` 目录也包含这六个同名声音库。数字后缀的含义和各库的实际分工仍需解析关联，不能把它们直接命名为六个派系或六位顾问。存在中文路径也不能证明所有提示都有中文配音。

本机 `audio_en.pack` 有 184,662 个 `.wem` 条目，`audio_base.pack` 有 163,350 个 `.wem` 条目。这些是整个包的媒体索引计数，包含顾问以外的内容；它们不能作为顾问台词数量或顾问覆盖率。

Wwise 声音库（`.bnk`）负责声音事件与播放对象等关联，`.wem` 是实际媒体。替换需要从事件追踪到对应媒体，保留对同一媒体的共用引用关系。工具流程可参见[音频 Mod 文档](https://www.tw-modding.com/wiki/Audio_modding)与 [AssetEditor 作者仓库](https://github.com/donkeyProgramming/TheAssetEditor)；工具说明不代表本机已经验证替换成功。

另一个直接影响定位的方法限制是：本机这 2,969 条记录的 `audio_clip` 字段全部为 `n`。不能把该字段直接当成可提取的音频文件名。后续须结合 `advice_thread`、声音事件及声音库对象继续追踪。

## 4. 对应文案的本地发现

本机简体中文包 `local_cn.pack` 包含 `text/localisation__.loc`。完整解析得到 212,411 条本地化记录，其中 2,926 条键以 `advice_levels_onscreen_text_` 开头。

以提示表的数字 `key` 拼接 `advice_levels_onscreen_text_<key>`，可在这个文本成员中匹配到 2,926 条提示；另有 43 条提示在这个成员中没有对应键。此结果仅覆盖该文件与该种匹配方式，不能据此把这 43 条判成缺失 DLC、未配音或运行时必定没有文字。仍需检查其他最终生效的包、隐藏提示、影片或不同文本入口等情况。

以下四条已经建立提示记录与实际中文文本的关联。证据 JSON 保存文字长度和 UTF-8 SHA-256，不收录整份原版文本。

| 提示 `key` | `advice_thread` | 身份 | 文本字符数 |
| --- | --- | --- | ---: |
| `1001682303` | `wh2_dlc13.camp.advice.lzd.warmblood_invaders.001` | `standard_advisor` | 40 |
| `1001950543` | `wh3_main_camp_narrative_shared_increase_control_02` | `standard_advisor` | 33 |

| `333684377` | `Play_wh3_dlc29_endtimes_narrative_nagash_nagash_003` | `nagash` | 20 |

这证明当前本机共享文本包中包含通用提示及 DLC 相关剧情文案，可在不进入相应战役的情况下读取。它没有证明每条文案都恰好对应一个音频，也没有完成以上四条的实际媒体提取或试听。

## 5. DLC 拥有权与资源覆盖

### 5.1 已安装条目的读取

对于已经存在于安装目录普通 `.pack` 中的条目，本次读取只需要文件系统访问、包索引和格式解码，没有以账号 DLC 许可决定是否展示或解压条目。未购买 DLC 不会使这种已安装条目在解析器中自动隐藏。

官方 FAQ 说明，未拥有的种族与传奇领主仍存在于超凡帝国中，可作为 AI 交互对象；拥有权决定玩家能操作哪些种族和领主。参见 [SEGA 官方 FAQ](https://support.sega.com/hc/en-gb/articles/51224684758929-Total-War-WARHAMMER-A-New-Player-Survival-Guide-FAQ)。这支持区分可玩权限与资源存在，但不能单独证明每条 DLC 专属剧情音频都已安装。

结合本地共享包中的 DLC 提示记录和实际文案，开发上可以先扫描已安装资源，无需把购买全部 DLC 作为发现音频和文案的前置条件。

### 5.2 完整覆盖的判断条件

| 层次 | 当前结论 |
| --- | --- |
| 提示定义可发现 | 本机提示表中发现多个 DLC 的记录，证据清单保存按线程标签查询的样本 |
| 实际文案可发现 | 已解析当前简体中文文本成员，并完成 2,926 条键匹配 |
| 声音库和媒体索引可发现 | 已检查列出的提示声音库，并验证英语与通用媒体包的索引 |
| 某条提示的实际声音存在 | 需完成对应事件到媒体 ID 的解析，不能用声音库存在替代 |
| 未购买某 DLC 时仍持有其全部资源 | 未检查账号 DLC 拥有列表，也未做拥有与未拥有的对照实验，未验证 |
| 全部 DLC 换声覆盖 | 未完成逐条音频映射与播放验证，未验证 |

资源发现还受实际安装版本、下载完整性、语言资源和后续覆盖包影响。表中找不到某个标签，也不能直接认定该 DLC 没有资源：线程命名可能沿用旧前缀、使用其他标签，或通过不同入口触发。

缺少可玩权限会限制直接以对应领主进入战役验收的范围。文案或媒体已经在本地时，静态读取仍可进行；其他账号或机器的实测结果应单独标注来源。

## 6. 换声 Mod 的建议实现与验证

### 6.1 资源清单

先明确目标是通用顾问换声，还是连同剧情旁白和特定战斗播报一起替换。按实际装载包及覆盖关系建立清单，覆盖所需语言，避免只查看一个 `audio_en.pack` 就宣称覆盖当前安装的所有语音。

每条目标记录建议保存提示 `key`、`advice_thread`、`advisor_name`、本地化键、语言、声音事件、声音库路径、媒体 ID、`.wem` 路径及哈希，并分别标记“已找到定义”“已找到文案”“已找到媒体”“已试听”“已替换验证”。当前 `audio_clip=n` 的占位值不作为媒体映射依据。

### 6.2 替换范围

共用媒体一次替换会影响所有引用位置，这是跨派系复用换声的依据。若只想改变一个派系的声音，而其他派系引用相同媒体，就需要研究事件或状态分支，不能直接覆盖共用媒体后仍声称只影响目标派系。

将自有替换资源交付为独立 `.pack`，保留游戏原包作为基线。单纯替换媒体、修改声音库和增加新声音事件应分别评估工具、编码和兼容要求；涉及声音库时需检查其他音频 Mod 的覆盖或合并关系。当前尚未选定或验证最终编码、声音库改造方式和运行时依赖。

### 6.3 最小验证矩阵

| 验证项 | 完成条件 | 当前状态 |
| --- | --- | --- |
| 提示表解析 | 行数、字段、文件末尾及身份计数一致 | 已完成 |
| 中文文案关联 | 记录键匹配与单文件未匹配项，保留样本哈希 | 已完成；43 条在当前成员未匹配，原因待定位 |
| 提示到媒体关联 | 从事件定位实际 `.wem`，检查文件存在与重复引用 | 待执行 |
| 单句换声原型 | 对应提示能播放替换内容，编码、音量与时长行为正常 | 待执行 |
| 共用提示跨派系 | 至少两个已拥有的不同派系触发目标提示，确认替换范围 | 待执行 |
| 专属剧情提示 | 覆盖所选旁白、序章或 DLC 专属提示并验证实际触发 | 待执行 |
| 完整资源审计 | 每个目标提示的文案、媒体、替换产物与遗漏原因可追踪 | 待执行 |

后续实机验证遵守仓库 Steam 主动离线约定，启动前取得本机新鲜后台离线回执。缺少所需可玩权限的案例保留为未验收，不以静态扫描通过替代运行时结果。
