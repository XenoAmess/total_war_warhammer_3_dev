# 招募候选刷新 0.2.1 设计

当前版本只保留领主/事务官刷新，迁都独立为 move_capital。包名、原刷新命名空间和存档履历保持；消息入口和业务层均拒绝旧迁都动作。

具体边界及最简验证见 [拆分设计](split-release.md)，原合并版本的完整设计见 [历史设计](mod-design-0.1.0-combined.md)。

刷新按钮使用原生 footer 中当前可见的招募按钮定位，放在其右侧；同时约束在面板与 footer 内，避开加载角色和省份切换控件。文字层单独测量、缩放和居中，关闭越宽的装饰火焰。锚点缺失、测量失败或空间不足时隐藏，不回落到顶部页签。

单击即冻结当前类别、回合、序号和候选指纹，关闭招募面板，等待旧角色卡片释放后提交一次请求。等待超时不提交，执行中忽略重复点击。成功后重开原类别，无确认和成功弹窗；错误及不确定结果仍提示。业务层的履历保护、过期检查和锁定规则不变。
