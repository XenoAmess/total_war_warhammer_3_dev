# 刷新专属版本最简验收

0.2.1 离线检查：Lua 5.1 编译、53 项刷新/界面/原生拒绝/元数据检查、语言 key、确定性重建和包内容检查。共用工具另有 58 项。

实机仅单独启用刷新 Mod 与 memreader Plus，加载独立存档；领主和事务官各刷新一次，核对新旧 ID、数量及受保护人物，正常招募一个新领主，确认城镇面板不再出现原迁都按钮。不测试两个拆分 Mod 同时启用，不重跑压力矩阵。

额外检查底部按钮在实际分辨率和 UI 缩放下不覆盖页签、招募、加载角色与省份切换控件，中英文文字居中且完整；单击不弹确认，成功后回到原类别。连击只产生一次请求，错误提示不能重放刷新。

发布前取得账号空闲证据，核对新包 SHA-256 和单独实机回执，更新既有条目 3830548217；0.2.0 的延期授权仅适用于旧 SHA，不自动套用于新包。新记录单独放在 acceptance-results-0.2.1.json，旧公开记录保留。

必要在线阶段查询远端两个启动器元数据键，真实订阅，检查 Subscribed bit 1、Installed bit 4、下载目录和同一 SHA，再核对旧启动器列表。完成后立即恢复主动离线，并取得新鲜读回，再从 Steam 订阅包启动游戏验证；单独的 DownloadItem 不计订阅验证。
