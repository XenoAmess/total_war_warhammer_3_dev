# 验收夹具源文件

这些文件只供审阅本次测试，未打入发布包。路径、存档和进程属于记录中的执行机器，不可当作其他机器的可运行默认值。

`bootstrap-template.lua` 是初始模板。`cold_reload.py` 在启动前将模板版本改为 0.3.3，并追加本次精确 release identity 与包 SHA 断言，生成实际分发命令。实际冷启动载入由上一层 `native.log` 的 `FINAL_COLD_PACK` 及验收 JSON 绑定；没有热加载生产实现。

城镇转让、瞬时研究科技、原版按钮操作和证据核验的源文件同时保留。科技夹具不代表完整研究流程；没有将基线存档载入记为刷新后状态持久化验收。
